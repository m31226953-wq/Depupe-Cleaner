**Dedupe-Cleaner** — это мощная утилита командной строки для поиска и автоматического удаления дубликатов файлов. Программа использует MD5 хеширование для точного сравнения содержимого файлов, игнорируя имена и даты создания.

## Проблема

Со временем на жёстком диске накапливается огромное количество дубликатов файлов:

- Скопированные папки с фотографиями
- Повторяющиеся загрузки из интернета
- Резервные копии с одинаковым содержимым
- Дубликаты музыки и видео

Это приводит к:

❌ Потере свободного места на диске  
❌ Беспорядку в файловой системе  
❌ Сложностям при поиске нужных файлов  
❌ Замедлению работы антивирусов и индексации  

---

## Решение

**Dedupe-Cleaner** автоматически:

✅ Сканирует все вложенные папки  
✅ Находит точные копии файлов (а не просто同名)  
✅ Удаляет дубликаты, оставляя один оригинал  
✅ Освобождает гигабайты места на диске  

---

## Как это работает

1. Программа обходит все файлы в указанной директории
2. Для каждого файла вычисляется MD5 хеш (цифровой отпечаток)
3. Файлы с одинаковым хешем считаются дубликатами
4. Из каждой группы дубликатов оставляется один файл (самый новый или самый старый)
5. Остальные файлы удаляются безвозвратно
