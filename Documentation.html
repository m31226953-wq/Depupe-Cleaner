использование

$ python main.py /путь/к/папке
$ python main.py /home/user/загрузки /home/user/рабочийстол -q
$ python main.py C:\Users\имя\Desktop -e .jpg .png -q
# сканирование без удаления
python main.py ~/загрузки

# сканирование и автоудаление
python main.py ~/загрузки -q

# сканирование нескольких папок
python main.py ~/загрузки ~/документы ~/рабочийстол -q

# оставить старые файлы
python main.py ~/документы -k oldest -q

примеры

# очистка папки загрузки
python main.py ~/Загрузки -q

# очистка нескольких папок
python main.py ~/Рабочийстол ~/Загрузки ~/Документы ~/Изображения -q

# удаление дубликатов изображений
python main.py ~/Изображения -e .jpg .png .gif -q

# оставить старые версии
python main.py ~/Документы -k oldest -q

# экспорт отчёта
python main.py ~/Загрузки -q --report очистка.json

# windows очистка профиля
python main.py C:\Users\%USERNAME%\Desktop C:\Users\%USERNAME%\Downloads -q

параметры

параметр описание пример
папка путь для сканирования python main.py ~/Загрузки
-e, --extensions фильтр по расширениям -e .jpg .png
-m, --min-size минимальный размер в кб -m 1024
-k, --keep оставлять newest или oldest -k oldest
-q, --quiet автоудаление без вопросов -q
-r, --report сохранить отчёт в json --report data.json

частые вопросы

файлы удаляются навсегда?

да. удаление происходит минуя корзину. запустите без -q для предварительного просмотра.

сколько места освободится?

запустите без флага -q чтобы увидеть количество дубликатов и объём места.

можно отменить удаление?

нет. удаление необратимо. сделайте резервную копию важных файлов.

почему некоторые дубликаты не удаляются?

файлы могут использоваться другой программой или недостаточно прав.

работает на linux и mac?

да. работает на любой платформе с python 3.6 и выше.
